zapper: mpv and FFmpeg
======================

zapper plays video with libmpv, the library form of the mpv media player,
which decodes through FFmpeg; its recording service, zapper-server, uses
FFmpeg's libraries directly. Neither is part of zapper's own code (MIT):
they are separate shared libraries, under their own license, which the two
programs load when they start.

  mpv     https://mpv.io
  FFmpeg  https://ffmpeg.org

Every zapper package contains those libraries, built by the zapper project
from mpv's and FFmpeg's released source with nothing under the GPL: mpv
configured with -Dgpl=false, FFmpeg without --enable-gpl, --enable-version3
or --enable-nonfree. They are therefore under the GNU Lesser General Public
License, version 2.1 or later.

  Linux (.deb, .rpm, Arch)  /usr/lib/zapper/: libmpv.so.2, and FFmpeg's
                            libavcodec, libavformat, libavutil, libavfilter,
                            libavdevice, libswscale and libswresample
  Windows                   libmpv-2.dll and FFmpeg's avcodec-*.dll and the
                            rest, beside zapper.exe
  macOS                     zapper.app/Contents/Frameworks/

A few other libraries are built into them (libplacebo, libass, dav1d and,
depending on the platform, FreeType, HarfBuzz, FriBidi, zlib and the shader
compilers Direct3D needs), each under its own license, all of them
LGPL-compatible. THIRD-PARTY-NOTICES-libmpv.txt beside this file lists them
with their versions and licenses, and carries every license's full text,
the LGPL's among them.

The source
----------

The exact source the library was built from, every tarball, is published
on zapper's GitHub releases page, in the libmpv release named in
THIRD-PARTY-NOTICES-libmpv.txt (tagged libmpv-<mpv version>-ffmpeg-<FFmpeg
version>-r<n>):

  https://github.com/francislavoie/zapper/releases

and the build script that made it is in zapper's own source, at
https://github.com/francislavoie/zapper (scripts/build-libmpv.sh, with the
list of sources in packaging/libmpv/sources.txt).

Replacing it
------------

The LGPL lets you use modified versions of these libraries instead. zapper
and zapper-server load whichever ones sit in the places listed above (libmpv
version 2 of its API, FFmpeg's of the same major versions), so replacing
those files with your own builds is all it takes.

On Linux the library takes a few ordinary libraries from your system
(audio, VA-API, Wayland, EGL, OpenSSL, FreeType, HarfBuzz, FriBidi,
Fontconfig): the package depends on them, and your distribution installs
and updates them under their own licenses.


zapper reaches libmpv through the libmpv2 and libmpv2-sys Rust crates
(LGPL-2.1), which are compiled into zapper itself: THIRD-PARTY-NOTICES-rust.txt
has their license and where their source is.
